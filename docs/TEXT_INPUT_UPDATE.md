# 文本优先与分步导航更新

日期：2026-10-08。

- 默认入口为“文本输入（推荐）”，图片识别 / OCR 为第二个可选入口；文本模式隐藏上传图片区域和重新识别按钮。
- 文本页使用可直接编辑的作文原文、粘贴提示和本地词数，突出“确认原文并评分”。
- 未提交有效的考试与题目设置时，“文本确认”显示灰色并禁用；侧栏、Ctrl+3 和内部导航采用相同入口条件。
- 完成第一步并继续后立即解锁；新作文重新锁定。考试或模式切换时按已完成的任务草稿恢复导航状态。
- 启用的按钮采用轻微的文字、边框和背景变色提示可操作性；禁用导航没有 hover 高亮，纯展示卡片保持静止。悬停不移动正文或分数，也不额外引入动画。
