- 真实 AI 评分、真实在线 OCR：**未验证**。新项目没有配置服务商凭据。全部网络测试使用替身，并阻止测试期间意外 HTTP 调用；这些通过结果不代表真实服务质量或可用性。
- 可选本地 OCR：未复制模型权重，真实权重推理未验证；相关线程行为用替身覆盖。
- 未评分草稿保留在当前进程，尚未实现关闭程序后的草稿恢复。
- 验证采用原生 Qt offscreen 渲染；实体显示器 DPI、系统输入法和人工连续键鼠操作尚待使用者在实际桌面环境检验。
